# tomi-piada


ToMi piada tem esse nome pois é junção do meu nome com o de um amigo. Seu personagem é o David, uma lagartixa simpática que gosta de contar piadas com a camisa do tio Max do Ben 10. 
Espero que esse projeto divirta e ajude a compreender melhor como funciona o javascript. 
Esse é um projeto aberto, mas não pretendo utilizar piadas que não sejam apropriadas a todos os públicos. Então também não gostaria que fossem utilizado do código para colocar outros tipo de piada.
Os desenhos da lagartixa David foram confeccionados por mim. E eu não gostaria que fossem utilizadas sem autorização. Favor entrar em contato caso necessite. 

Esse projeto tem como objetivo expandir os conhecimentos em javascript, css e APIs. 
O javascript é extremamente versátil e para algumas pessoas é difícil compreender tantas possibilidades e o que há além do que os cursos básicos mostram.
Por isso meu objetivo é manter ele lotado de comentários para que quem esteja aprendendo possa entender o que foi feito e o quais as possibilidades com o javascript. 
Alguns comentários foram feitos pelo Gemini para deixar mais didático, mas deixei a minha forma de pensar nos comentários que eu fiz, então perdões a minha cabeça aloprada de TDAH.
